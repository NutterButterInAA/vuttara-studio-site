Vuttara Studio 0.2.0

Foundation milestone

Application foundation

  • Native C++20 and Qt 6 application shell.
  • Vuttara Studio application branding and splash screen.
  • Direct3D 11 preview-engine foundation.
  • Initial Inno Setup installer assets.

Update-system foundation

  • Stable update-channel metadata format.
  • GitHub Releases installer-hosting structure.
  • HTTPS and semantic-version validation.
  • SHA-256 installer verification structure.
  • Installation and restart protection during streaming, recording, and replay-buffer activity.

Not yet published

The Vuttara Studio 0.2.0 installer has not been published. The download button remains disabled until the installer is built, validated, uploaded, and assigned a SHA-256 checksum.
