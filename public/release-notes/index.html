Vuttara Studio 0.2.9 Stable

Published July 29, 2026

Audio Mixer V2 adds native Windows desktop and microphone capture, reliable mixed-audio recording, improved metering, and safer output levels.

  1. Added native WASAPI desktop loopback and microphone capture routed into a 48 kHz stereo program bus.
  2. Added Desktop Audio and Microphone mixing with volume, mute, logarithmic dBFS meters, and green, yellow, and red level zones.
  3. Improved multichannel downmixing and limiter behavior to prevent clipping and audible distortion.
  4. Improved WAV recording continuity so recordings retain their beginning, ending, and elapsed timeline, with safe .part-file finalization.
  5. Added bounded mixed-audio output queueing and automated audio routing and recording-continuity tests.
  6. Documented that mixed PCM is queued for output while RTMP audio encoding and transmission remain future work.

Vuttara Studio 0.2.8 Stable

Published July 27, 2026

Adds a functional Windows audio mixer with live Desktop Audio and Microphone monitoring, device selection, persistent volume and mute controls, automatic device refresh, and safe fallback when a selected device becomes unavailable.

  1. Added live Desktop Audio endpoint monitoring.
  2. Added live Microphone endpoint monitoring.
  3. Added Windows playback-device selection.
  4. Added Windows recording-device selection.
  5. Added support for following the default Windows audio devices.
  6. Added independent Desktop Audio and Microphone level meters.
  7. Added independent volume controls for both mixer channels.
  8. Added independent mute controls for both mixer channels.
  9. Added automatic fallback when a saved audio device is unavailable.
  10. Added automatic audio-device refresh every three seconds.
  11. Added a manual audio-device Refresh button.
  12. Added persistent mixer device, volume, and mute settings.
  13. Added atomic audio mixer settings writes to prevent corrupted settings.

Adds persistent scene management so creators can create, switch, rename, duplicate, delete, reorder, and automatically save scenes.

  1. Create, switch, rename, duplicate, delete, and reorder scenes.

  3. Automatically save scene data and restore image, display, and window sources.
